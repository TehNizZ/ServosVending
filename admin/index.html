Send requests to a Google Sheet (recommended)

  1. Open your Servos Placement Requests sheet in Google Sheets.
  2. Choose Extensions, then Apps Script. Delete anything in the editor and paste the script below. Click Save.
  3. Click Deploy, then New deployment. Pick type Web app, set Execute as: Me and Who has access: Anyone. Deploy and approve the permissions.
  4. Copy the Web app URL (it ends in /exec) and paste it into the box above.

If you change the script later, use Deploy, then Manage deployments, then edit and pick "New version". A Google Form pre-filled link also works in the box above.
